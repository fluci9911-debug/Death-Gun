## What is this?

Death Gun is a small top-down survival shooter I built while experimenting with game programming, enemy AI, procedural audio, mobile controls, and generally seeing how much stuff I could cram into a relatively small JavaScript project.

The original plan was "just make a zombie shooter."

A few days later there were ghosts, vampires, boss fights, blood effects, mobile controls, physics objects, and a procedural soundtrack.

So things escalated.

## 🎮 Features

### 🔫 Weapons

- Pistol
- Rifle
- Shotgun

Each weapon has different recoil, fire rate, ammo capacity, and playstyle.

### 👾 Enemies

🧟 Zombies  
🧛 Vampires  
👻 Ghosts  
💀 Boss Zombie

The goal was to make enemies behave differently rather than simply giving them more health.

### 💥 Combat

- Wave-based survival gameplay
- Bullet collision system
- Ammo pickups
- Physics interactions
- Persistent corpses
- Blood particle effects

### 🎵 Audio

- Procedural soundtrack
- Procedural sound effects
- Built with ZzFX
- No audio files shipped with the game

### 📱 Mobile Support

- Dual virtual joysticks
- Responsive scaling
- Touch controls
